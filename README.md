# Employee Salary Prediction System

## 📌 Project Overview
The Employee Salary Prediction System is a Machine Learning project that predicts employee salaries based on factors such as age, gender, education level, job title, and years of experience.

This project uses data preprocessing, feature engineering, and machine learning techniques to analyze employee data and estimate salary values accurately.

---

## 🚀 Features
- Employee salary prediction using Machine Learning
- Data preprocessing and cleaning
- Handling duplicate and missing values
- Exploratory Data Analysis (EDA)
- Feature encoding for categorical data
- Model training and evaluation
- Salary prediction based on employee details

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## 📂 Dataset Information
The dataset contains employee-related information such as:

- **Age**
- **Gender**
- **Education Level**
- **Job Title**
- **Years of Experience**
- **Salary**

Dataset Size:
- **375 Rows**
- **6 Columns**

---

## 📊 Data Preprocessing
The following preprocessing steps were performed:

- Loaded dataset using Pandas
- Checked data types
- Removed duplicate values
- Handled missing values
- Converted categorical features into numerical format
- Prepared dataset for model training
